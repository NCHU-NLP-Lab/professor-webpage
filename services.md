# Deployed AI Services — NCHU NLP Lab (Yao-Chung Fan, Director)

The NCHU NLP Lab operates a family of production AI systems spanning campus services, cross-institution healthcare deployments, and Indigenous-language preservation.

## AI 興學伴 (eduxplore)

Campus learning advisor integrating NCHU's institutional information (course search, faculty lookup, learning resources) into a conversational interface.

- URL: https://eduxplore.nlpnchu.org/
- Audience: NCHU students and faculty
- Status: **Live**
- Positioning: NCHU LearningHub

## 神農 TAIDE

Retrieval-Augmented Generation (RAG) architecture built on top of TAIDE — the Taiwan-developed traditional Chinese LLM.

- Tech stack: TAIDE LLM + RAG
- Status: **Live**

## Fact-Checking System

End-to-end fact verification system using Claude API and the Model Context Protocol (MCP) to coordinate retrieval, evidence checking, and verdict generation.

- Tech stack: Claude API + MCP
- Status: **Live**

## Changhua Christian Hospital Consultation System

Smart question-answering system for hospital visiting rules and policies, deployed in partnership with Changhua Christian Hospital — the lab's flagship **cross-institution** deployment.

- Audience: Hospital visitors and staff
- Status: **Live**
- Significance: Demonstrates the research-to-deployment pipeline beyond campus boundaries.

## Amis (阿美族語) Dialogue System

LLM + speech recognition system for Amis, a low-resource Indigenous Taiwanese language. Combines speech-to-text, dialogue understanding, and translation to support Indigenous language preservation, education, and accessibility.

- Tech stack: LLM + ASR
- Status: **Research / In deployment**
- Audience: Amis speakers, language educators, researchers
